# Lumos Client 0.4.7

## New
- **Updates install by themselves.** When LumosClient starts and finds a new version, it downloads it, checks it against the release's SHA-256, swaps itself and restarts — no uninstalling, no clicks. It never updates while a game is running. Turn it off in Settings > Updates > Automatic. (From 0.4.6 or older, click Update once to reach this version; after that it's automatic.)

## In the latest all-in-one game (updates by itself)
- **Faster frames:** mod settings are kept in memory instead of read from disk every frame; Lumos Map and World Map spread their chunk scanning over frames (at most about 8% of a frame, paused on lag spikes) instead of spending a fixed 1.5–2 ms; Lumos HUD reuses its layout when nothing on it changed. Measured +0–5% FPS, no regressions.
