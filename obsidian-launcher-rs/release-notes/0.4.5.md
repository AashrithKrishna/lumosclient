# Lumos Client 0.4.5

## Fixed
- **Servers see the client as "horizon", not "vanilla".** Horizon told every server it was the vanilla game, so some anticheats took it for a brand spoofer. It now always reports "horizon", as staff expect from a Horizon-based client.
- **Placed blocks no longer vanish after joining a world saved on another hotbar slot.** The game and the server disagreed about the selected slot, so every block was refused and put back.
- **Spear lunge no longer stutters the camera on servers.**
- **Lumos Map waypoint markers now draw on screen.** They now behave like Xaero's: only the current dimension, only in front of you, small, with the distance shown on the one you look at.

## New in Discover
- **Item Scroller:** Item Scroller's own controls. Ctrl+click moves one item, Alt+click moves every matching item, Shift+drag moves stacks, the scroll wheel moves items, hold A for recipe slots, Ctrl+C / Ctrl+Alt+C for mass crafting, and favourite villager trades.
- **World Map:** a fullscreen map of everywhere you explored, saved per world and server, with smooth zoom, cave layers, dimensions, waypoints shared with Lumos Map, and PNG export.
- **Shaders from Modrinth:** Discover's shader list now includes Modrinth's shader packs, with checksums verified on download.
- Attribute swapping now works in singleplayer and LAN too, as in vanilla.
