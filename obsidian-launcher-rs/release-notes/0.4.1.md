# Lumos Client 0.4.1

## Fixed
- **Instance Mods tab stayed empty:** a helper the list uses went missing in 0.4.0, so an instance's Mods, Resource Packs and Shaders tabs never loaded. They load again, native Horizon mods included.
- **Repeated notices:** the same message no longer stacks up when you click Install more than once.
- **"Horizon couldn't prepare its files" with native mods:** a native build's own Horizon only accepts the 26.3 version file it was made with, which Mojang has since republished. Lumos now saves that exact file (checked by SHA-1) beside the build before launching.
- **Playtime and crash help on the wrong instance:** switching instances while a launch was still downloading credited the playtime, and pointed the crash explainer's buttons, at the instance you switched to.
- **Discover's Content Hub** no longer sends a Modrinth project to a Horizon instance (or a Horizon one to a Java instance); it says why instead.
- **Crash explainer** no longer gives up silently on crashes whose stack trace has non-English characters.
- **Doubled messages:** a failed repair, and a CurseForge-only modpack, each showed their notice twice.
