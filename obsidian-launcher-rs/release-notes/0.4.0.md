# Lumos Client 0.4.0

0.4.0 is the biggest update since 0.3.0. Lumos now has its own in-game HUD and capes, handles NeoForge, Forge and modpacks, installs mod dependencies for you, can update itself on Mac and Windows, and runs on Intel Macs and Linux as well as Apple silicon Macs and Windows.

## New

**In-game**
- **LumosHUD:** a Lunar-style HUD with 18 modules (FPS, CPS, coordinates, keystrokes, direction, biome, armor, potion effects, ping, clock, server address, day counter, speed, reach, combo, item counter, memory and toggle sprint). Modules have icons, there is a Lunar and a Minimal style, and you edit the layout in game by pressing Right Shift. Works on Fabric 1.21.6 to 1.21.11, and you choose the modules per instance.
- **Horizon HUD switches:** Horizon 26.3 instances get Horizon's own HUD options in the same place.
- **Lumos capes:** 12 free cape designs. Pick one on the Skins page with an Ely.by account; other Lumos players see it in Fabric 1.21.11.
- **Ely.by skins in one click:** wear a skin from the Ely.by catalog, or upload your own, without leaving the launcher.

**Versions, mods and modpacks**
- **NeoForge and Forge** versions can be installed as instances.
- **Modrinth modpacks:** import an `.mrpack` file or use the new Modpacks tab.
- **Loader-aware Discover:** results fit the instance's Minecraft version and loader. Mods already in the instance show as installed, based on the files on disk.
- **Automatic dependencies:** installing a mod also installs the mods it requires. Optional dependencies are suggested, never added on their own.
- **Compatibility warnings and Check mods:** Lumos warns before installing a mod that would stop the game starting, and Check mods looks for missing dependencies, incompatible mods and duplicates in an existing instance.
- **Horizon 26.3 registry:** Horizon instances browse Horizon's own mods, shader packs and resource packs. Native Rust mods are delivered as ready-made cloud builds instead of being compiled on your computer, and a combined build lets them mix in one instance.

**Instances**
- **Per-instance settings:** memory, window size and Java arguments for each instance, plus a clear Delete button.
- **Boost FPS:** on Fabric instances, adds performance mods for the instance's version (Sodium, Lithium, FerriteCore, ImmediatelyFast, Entity Culling, More Culling, Dynamic FPS, and RetiNO on a Mac) where Modrinth has them, and sets tuned Java flags.

**Looking after Lumos**
- **Auto-updater:** Lumos checks GitHub releases for a newer version. On Mac and Windows it downloads the update, checks it against the release's SHA-256 and installs it. If a release has no checksum, it opens the release page instead.
- **Crash explainer:** when the game closes with an error, Lumos reads the crash report and log and suggests a likely cause, such as a mod problem, too little memory or the wrong Java, and can switch off the mod behind it.
- **Repair instance:** checks the game files and Java against their checksums and downloads damaged or missing ones again. Worlds and mods aren't touched.

**Platforms**
- One universal Mac app for Apple silicon and Intel (macOS 13 or newer), a Windows x64 build, and a Linux x86_64 build.

## Improved

- Notices now appear in the top-right corner and let clicks through. Notices from one install are grouped.
- Discover no longer repeats the same search twice in a row.
- Native Horizon mods prefer the combined build, and existing instances move onto it.
- Horizon builds from the cloud keep working even if one mod's build fails.

## Fixed

- Horizon's mouse pointer now shows up again when the window regains focus.
- Horizon's controller support is a setting that is off by default. On Windows, a device that only looked like a controller could hide the pointer in menus.
- Fixes to instance safety and Windows file paths found in review.

## Known limitations

- Lumos still has no Microsoft sign-in, so it can't join online-mode servers such as Hypixel. It plays singleplayer, LAN and servers that allow offline or Ely.by players.
- LumosHUD works on Fabric 1.21.6 to 1.21.11 only. Lumos capes show in Fabric 1.21.11 only.
- Boost FPS is for Fabric instances.
- The Linux build doesn't update itself; Lumos tells you about new releases and points you to the download.
- The builds aren't signed with a paid certificate, so macOS and Windows ask before opening Lumos the first time.
- Horizon's native mods as cloud builds are available on Apple silicon Macs and Windows x64.

## Install and upgrade

Downloads are on the [releases page](https://github.com/AashrithKrishna/lumosclient/releases/latest).

| Computer | File |
|---|---|
| Mac (Apple silicon or Intel, macOS 13+) | `Lumos.dmg` |
| Windows 10 or 11 (64-bit) | `Lumos-Windows-x64.zip` |
| Linux (x86_64, glibc 2.35+, WebKitGTK 4.1) | `Lumos-Linux-x86_64.tar.gz` |

- **First time:** on Mac, drag Lumos into Applications, then right-click it and choose Open the first time. On Windows, unzip and run `Lumos.exe`; if "Windows protected your PC" appears, choose More info, then Run anyway. On Linux, extract the archive and run `./lumos-launcher` (`./install-desktop-entry.sh` adds it to your applications menu).
- **Coming from 0.3.0:** 0.3.0 can't update itself, so install 0.4.0 by hand once, over your old copy. Your instances, worlds and settings live in `~/LumosClient` (`%USERPROFILE%\LumosClient` on Windows) and are kept.
- **After 0.4.0:** on Mac and Windows, Lumos tells you when a new version is out and can install it for you.
