# Lumos Client 0.4.4

## Fixed
- **Only the native mods you installed run in the all-in-one 26.3 game.** Every other built-in mod is switched off before each launch, so none of them changes gameplay, and they're hidden everywhere in the game (Options > Mods, Key Binds, Mod Menu).
- **A mod you switch off stays off.** Before, every launch switched your installed native mods back on, undoing a toggle made in the game or in the Mods tab.

## In the latest all-in-one game (updates through Discover)
- Attribute swapping on servers: a hotbar swap and a hit in the same tick now reach the server with the new item, as in vanilla.
- Physics Mod's first-run setup can no longer block clicks on the title screen.
- Lumos Map: smoother cave view, no hitch on map hotkeys, safer saves, and several smaller fixes.
