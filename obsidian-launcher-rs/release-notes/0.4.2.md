# Lumos Client 0.4.2

## Fixed
- **Voice chat on Mac:** Lumos now asks macOS for the microphone on behalf of your games, so voice chat mods (Simple Voice Chat on Fabric, Horizon Voice Chat) can hear you. Allow it when macOS asks.

## New
- **In-game Discover for Horizon 26.3 (Lumos Discover mod):** browse and install Horizon mods, resource packs and shaders without leaving the game. Packs and shaders apply live; native mods ask for a restart, and Lumos installs them when the game closes and launches it again.
- **New Lumos mods for Horizon 26.3:** LumosHUD (Right Shift editor), Lumos Map (minimap, waypoints, world map), Freelook and a Fullbright key, alongside Durability Tooltip, Totem Counter, Particle Rain and Paginated Advancements.
