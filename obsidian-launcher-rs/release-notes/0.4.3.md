# Lumos Client 0.4.3

## Fixed
- **Native mods disappeared from Discover:** on 18 November Horizon's mod registry moved all 137 native mods into an archive while it switches to a new mod format. Lumos now keeps a frozen copy of those listings (the downloads are unchanged and still checked by SHA-256), so Discover shows and installs them again.
- **Discover and native builds:** mods that can't share a game with the instance's are marked "Needs another instance", mods outside the all-in-one game say "Install (own game)", and the cards update right after an install or removal.

## New
- **Boost FPS for Horizon instances:** turns on Horizon's own entity, particle and hidden-leaf culling and its block-entity caches.
- **Resource packs from Modrinth for Horizon 26.3:** Discover's Resource Pack tab on a Horizon instance now browses Modrinth's packs made for 26.3 (Horizon reads Java resource packs), with Horizon's own registry one click away.
- **Shaders are back in Discover:** Horizon's registry archived its shader packs too; Lumos lists them again from its saved copy (they still run in Lumos's Horizon games).
- **Ely.by sign-in no longer stops the game when your network's DNS misbehaves:** Lumos fetches Ely.by's sign-in details itself before launch (through encrypted public DNS if your router can't find Ely.by) and hands them to the game. If Ely.by can't be reached at all, the game still starts, with default skins and capes for that session.
